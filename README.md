# Planetário

Esse pequeno projeto foi um desafio proposto pelo meu curso, Talento Tech, Governo do Estado do Paraná.

Um pequeno app com uma interface simples e amigável, foi projetado para uso em celulares Android (a sua funcionalidade no iOS é desconhecida). Sinta-se à vontade para baixá-lo em seus celulares. Ele foi projetado para listar planetas e armazená-los em seu dispositivo.

Aos usuários de iPhone, se baixarem este app, por favor, relatem a sua experiência.
