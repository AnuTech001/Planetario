# Planetário

Esse pequeno projeto foi um desafio proposto pelo meu curso, Talento Tech.

Um pequeno app com uma interface simples e amigável, foi projetado para uso em celulares Android (a sua funcionalidade no iOS é desconhecida). Sinta-se à vontade para baixá-lo em seus celulares.

Aos usuários de iPhone, se baixarem este app, por favor, relatem a sua experiência.
